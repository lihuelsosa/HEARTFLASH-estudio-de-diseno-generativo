## ✨ Overview

**HEARTFLASH (Vectorheart)** is a parametric generative design suite created for digital artists, sound designers, and visual creators. It generates high-precision vector artwork, futuristic HUD interfaces, circuit patterns, and Y2K aesthetic graphics in real-time.

---

## 🎨 Generative Modes

- ◈ **VECTORHEART:** Sharp angular geometry, chrome-inspired vector flourishes, and Y2K cyber-aesthetics.
- ⚡ **CIRCUIT:** Procedural PCB trace generation, bus lines, and electronic schematic patterns.
- 🖥️ **HUD:** Sci-Fi heads-up display telemetry, target reticles, radar grids, and data readouts.
- 👾 **GLITCH:** Pixel displacement, digital artifacts, signal noise, and data corruption aesthetics.
- 📐 **BLUEPRINT:** Technical architectural grids, wireframes, and vector dimensioning lines.
- 🌀 **FLOW:** Smooth organic vector curves, fluid dynamics, and wave field modulations.
- ☸️ **SACRED:** Parametric sacred geometry, mandalas, and golden ratio spiral constructions.
- 🔣 **GLYPH:** Futuristic alien typography, rune generation, and cybernetic iconography.

---

## 🚀 Features

- 🎛️ **Full Parametric Control:** Fine-tune complexity, density, stroke weight, rotation, symmetry, and color palettes.
- ⚄ **One-Click Randomizer:** Instant procedural generation of unique visual assets.
- 📥 **High-Res Export:** Download high-resolution PNG renders or scalable **SVG vector files** ready for laser cutting, 3D printing, or graphic design software (Illustrator, Inkscape, Photoshop).
- ⏱️ **Real-time FPS & Performance Engine:** Smooth 60 FPS Canvas rendering with interactive HUD controls.

---

## 🛠️ Tech Stack

- **Frontend:** Vanilla JavaScript (ES6+), HTML5 Canvas API, SVG DOM manipulation.
- **Styling:** Custom CSS3 HUD interface, glassmorphic UI, responsive grid layouts, and Google Web Fonts (`Orbitron`, `Chakra Petch`, `Tektur`, `Share Tech Mono`).
- **Zero Dependencies:** Pure web standards without heavy external frameworks.
